## 概要

Three.jsを使って3D空間でフリーキックを蹴るゲームアプリです。
ボールの軌道は物理エンジン（Cannon-es）でシミュレーションされます。

## ゲームモード

起動するとタイトル画面で5つのモードを選べます。

- **フリープレイ**: 好きなだけシュートしてゴール数を競うエンドレスモード
- **ステージモード-α**: Stage1〜10をクリアして進む標準難度のミッションモード
- **ステージモード-β**: αより高難度。サイドネット／ポスト当て／ボールを追う**AIキーパー**などの難ミッション
- **ステージモード-γ**: **球数制限**チャレンジ。制限球数以内にノルマ達成・連続ゴール・四隅ビンゴ・スコアアタックなどの累積ミッションをこなす
- **ステージモード-δ**: **風**のチャレンジ。横風・向かい風・追い風を読んで狙いをずらす新感覚ステージ

## ゲームの遊び方

PC（マウス）・スマホ（タッチ）共通の操作です。

- **ボールを手前にドラッグ**して狙う（強く引くほどパワーUP）
- ドラッグの**左右**でコース、**引く量**で高さ（仰角）が決まる
- 画面下の **CURVE バー**を左右にスライドしてカーブ量を調整 🍌
- **指／マウスを離す**とシュート
- ゴール枠に入れて得点を狙え！

> 💡 カーブは方向操作と独立しているので、まっすぐ狙いながら大きく曲げることもできます。設定したカーブ量は次のキックにも引き継がれます。

### ステージモードについて

α・β・γ・δいずれも全10ステージ。クリアすると次のステージへ進み、進むほど難易度が上がります。
ステージごとに異なるミッションが課されます。

**ステージモード-α（標準）**

- ⚽ **ゴールを決める** — 基本ミッション
- 🥅 **クロスバーに当てる** — バーを狙い撃つ
- 🎯 **的・コーナーを狙う** — ゴール内の指定ゾーンを通す
- 🧱 **障害物・壁をよける** — 壁や動くキーパーをかわして決める（カーブが活躍！）

**ステージモード-β（高難度）**

- 🥅 **サイドネットを狙う** — ゴール左右端の深い位置に突き刺す
- 🎯 **左／右ポストに当てる** — 細いポストをピンポイントで狙う
- 🧤 **AIキーパーを抜く** — ボールを追ってくるキーパー。速いシュートやカーブでないと止められる！

**ステージモード-γ（球数制限）**

- ⚽ **ノルマ** — 制限球数以内に決められた本数を決める
- 🔥 **連続ゴール** — 1球も外さず連続で成功させる
- 🎰 **ビンゴ** — 複数の的を順不同ですべて制覇する
- 🏆 **スコアアタック** — 隅ほど高得点のゾーンで目標点を稼ぐ（球切れで未達なら最初から！）

**ステージモード-δ（風）**

- 💨 **横風** — ボールが風下へ流される。狙いを風上へずらすか、風に乗せてカーブを増幅！
- 🌬️ **向かい風／追い風** — 失速や伸びを計算してパワーを調整
- 最終盤は嵐級の風＋壁＋AIキーパーの複合ミッション

> 失敗しても何度でも挑戦できます（無制限リトライ）。条件を満たすと「STAGE CLEAR」、Stage10をクリアすると「ALL CLEAR」！

### 主な機能

- **実測値ベースのリアル物理** — 空気抵抗（二次抗力）・マグヌス効果・スピンの持続・芝のバウンド・転がり抵抗までシミュレーション。FIFA規定の質量・ゴール実寸
- マグヌス効果によるカーブシュート（方向操作とは独立したスライダーで調整）
- **風のシミュレーション**（δステージ）— 横風・向かい風・追い風が対気速度として空力計算に入る
- リアルなゴールネット演出 — 当たった位置を中心に波打つネット、バー／ポストの反発、得点時の発光
- **WebAudio合成の効果音** — キック音・ポストの金属音・ネットのこすれ音・観衆の歓声・クリアのホイッスル（音源ファイル不使用）
- リアルなピッチ — 刈り込みストライプの芝、実寸のペナルティエリア白線・PKスポット・アーク、広告ボード、五角形パネルのボール
- キック後にボールを目で追うカメラワーク
- フリープレイ＋4種のステージモード（α=標準 / β=高難度 / γ=球数制限 / δ=風）
- パワー／カーブを表示するメーターUI
- スマホ対応（タッチ操作・レスポンシブ表示）
- 成長過程アーカイブ — 過去バージョン（`/v1/`・`/v2/`）を凍結保存し、最新版と並べて公開
